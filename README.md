# ReScore

Web application that lets students of university residences organize
sports matches between residences, with a full match history and an
overall ranking.

Launched in Pau for UPPA students, it is designed from the start to
extend to any city in France by adding data only, without changing the code.

## Context

University residences (CROUS and private) have no tool to organize
matches between them: exchanges happen in messaging groups, scores get
lost and there is no ranking.

## Goals

- Create a positive rivalry between residences.
- Reserve access to real students through university e-mail verification.
- Keep a complete, searchable history of every match played.
- Stay free for users and for development.
